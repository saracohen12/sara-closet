## לפני שמשהו נסגר בחשבון הזה
1. **להוריד את כל הקבצים מההודעה בשיחה** (כל קובץ מצורף, לחיצה ← הורדה). לשמור בתיקייה אחת במחשב או בדרייב.
2. **להוריד את התמונות:** במחשב, ב-Chrome, לפתוח את האתר ← "⚙️ פאנל ניהול" ← "💾 גיבוי כל התמונות והנתונים". להוריד כל קובץ ZIP ברשימה (בערך 7 קבצים, כ-120MB כל אחד). קובץ שנכשל, לוחצים עליו שוב.
3. **לשתף את האתר עם החשבון השני:** באתר, כפתור השיתוף (Share) ← להוסיף את המייל של החשבון השני. כך החשבון השני יוכל להעתיק את כל התמונות ישר מהאתר, בלי להעלות אותן מחדש.
4. **לא למחוק כלום** בחשבון הזה: לא את האתר, לא את הפרויקט ולא את התמונות, עד שהאתר החדש עובד.
