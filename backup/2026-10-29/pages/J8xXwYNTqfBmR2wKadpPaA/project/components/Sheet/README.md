# Sheet

חלון שנפתח מעל המסך: בטלפון מלא מסך, במחשב ממורכז עם פינות `radius-xl`.

- כותרת דביקה למעלה: שם בגופן הכותרות, שורת הסבר קטנה ב-`muted`, וכפתור ✕ עגול 42px.
- הגוף נגלל בתוך החלון (overflow-y auto). חלון שלא נגלל הוא תקלה: כך פספסנו קטגוריות בגרסה 163.
- רקע `surface`, צל `shadow-sheet`, מסך מאחור כהה שקוף.
- בתחתית החלון מקום לכפתורים משניים ("🏠 למסך הבית", "📊 פרטים נוספים").
