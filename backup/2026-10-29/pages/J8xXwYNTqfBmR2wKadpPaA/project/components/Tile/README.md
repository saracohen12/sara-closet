# Tile

אריח מהיר במסך הבית: אייקון קו בעיגול, מספר (אם יש) ותווית.

- זכוכית: `glass`, קו לבן 1px, `shadow-1`, `radius-lg`. בטלפון 4 בשורה, ובמסך צר מאוד 2.
- האייקון 20px בצבע `camel-ink`, בתוך עיגול 40px עם מעבר מ-`sand` אל `blush`.
- המספר בגופן הכותרות (`display`), התווית ב-`caption` בצבע `muted`.
- האריח "מה יש לי בארון" הוא היחיד הכהה (מעבר `espresso` אל `cocoa`), והוא ראשון בשורה, כי זו הפעולה ששרה צריכה הכי הרבה.
- אריח בלי מספר מציג את התווית מודגשת במקום המספר.
