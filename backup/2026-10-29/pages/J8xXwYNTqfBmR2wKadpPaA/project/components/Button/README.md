# Button

כפתורי פעולה, תמיד בצורת גלולה (`radius-pill`), בגובה 44px לפחות.

- **ראשי:** מעבר מ-`espresso` דרך `cocoa` אל `camel`, טקסט לבן, `shadow-glow`. רק אחד במסך ("בניית לוק", "שמירה").
- **לבן:** `card` עם קו `line`. לפעולות משניות ("פאנל ניהול", "↩ לארון").
- **קישור:** בלי רקע, קו תחתון 2px בצבע `camel`. לפעולה שלישית ("הלוקים שלי").
- הטקסט אומר מה יקרה. אימוג'י בתחילת הטקסט מותר כשהוא עוזר לזהות מהר.
- כשאין מקום בשורה, הכפתורים עוברים לשורה שנייה. אף פעם לא נדחסים לעיגול ולא שוברים מילה.
