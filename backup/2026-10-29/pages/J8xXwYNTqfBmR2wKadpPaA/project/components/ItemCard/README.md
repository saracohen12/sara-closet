# ItemCard

כרטיס של פריט אחד בארון: תמונה, שם, צבע ומידה, ותגית מצב כשיש.

- `card`, `radius-lg`, `shadow-1`, ריפוד 6px. התמונה ביחס 3:4 בפינות 18px.
- שם הפריט ב-`item-name` (800), שורה אחת או שתיים. צבע ומידה ב-`caption` בצבע `muted`, מופרדים ב-" · ".
- תגית מצב בפינה העליונה: גלולה לבנה עם נקודה בצבע המצב (`ok` הגיע, `warn` עוד מעט, `bad` היום אחרון). הטקסט נשאר כהה, הצבע רק בנקודה.
- מחירים לא מופיעים על הכרטיס. הם בתוך חלון הפריט, תחת "פרטים נוספים".
- לחיצה פותחת את חלון הפריט. לחיצה ארוכה פותחת פעולות מהירות.
